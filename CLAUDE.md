# CLAUDE.md

This file exists only because Claude Code loads it by name. It contains no rules of its
own.

**Read [AGENTS.md](AGENTS.md) and follow it.** That file is the single source of truth for
every coding agent on this project, whatever model or harness runs it. It covers the
commands, layout, hard technical rules, verification, conventions, and the `work/`
feature-file workflow that every change must follow.

Before doing anything else in a session:

1. Read `AGENTS.md`.
2. Read `DECISIONS.md`.
3. Read `work/todo.md`.
4. Find or create your feature file under `work/`.

If anything here ever disagrees with `AGENTS.md`, `AGENTS.md` wins.
